# Remediation Workspace

A minimal fixture repository used as the source for the XZardgz git write
operations demo. In a real workflow XZardgz would write security or technical
review findings here, then create a branch, commit the reports, and open a pull
request.

## Structure

- `findings.md` - Placeholder for generated review findings.
- `requirements.txt` - Runtime dependencies.

## Notes

This fixture is intentionally minimal. The git write operations demo is
primarily about the `create_branch`, `commit_paths`, and `push_branch`
primitives, not about what is in the repository.
