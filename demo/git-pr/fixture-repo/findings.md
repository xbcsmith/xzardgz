# Review Findings

This file is a placeholder that XZardgz would replace with generated report
content when running a workflow with pull request creation enabled.

In a real workflow run, XZardgz produces one or more report files in the
workspace and then:

1. Creates a timestamped branch (`xzardgz/<ulid>`).
2. Stages the report files.
3. Commits them with a governance-compliant message.
4. Pushes the branch to the `origin` remote.
5. Opens a pull request targeting the configured base branch.
